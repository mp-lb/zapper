This folder follows a strict positioning sequence rather than a narrative report.

## Flow

- `source-material.md` lists the evidence available in the repo and user prompt.
- `product-features.md` states what Zapper does based on that evidence.
- `list-of-competitors.md` names the products and behaviors buyers would use instead.
- `unique-capabilities.md` narrows the feature set to the claims alternatives would struggle to match honestly.
- `value-drivers.md` explains why those unique capabilities matter in practice.
- `ideal-customer.md` identifies who feels that value most strongly.
- `market-context.md` chooses the comparison frame that makes the value easiest to understand.
- `positioning-statement.md` compresses the sequence into one concise market claim.
- `open-questions.md` captures the facts still missing or uncertain.

## Reading Order

- Start with `source-material.md` if you want to validate the evidence base.
- Start with `positioning-statement.md` if you only need the current output.
- Use `open-questions.md` before publishing external positioning, because the repo contains both shipped docs and forward-looking design notes.
